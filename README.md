# Изучение частых слов и фраз Корана

Этот репозиторий содержит базу данных самых часто встречающихся слов, глаголов, частиц и устойчивых выражений Корана с огласовками (ташкилем), транскрипцией и переводом на русский язык.

---

## 📂 Файлы в папке

1. `quran_frequent_words.tsv` — готовый датасет для импорта в **Anki** или любое приложение для карточек (разделитель — табуляция, теги включены).
2. `trainer.py` — консольный интерактивный тренажер на Python (можно тренироваться прямо в терминале).

---

## 🚀 Вариант 1: Импорт в Anki (Рекомендуется)

### Шаг 1. Установите Anki
* Скачайте приложение с официального сайта: [apps.ankiweb.net](https://apps.ankiweb.net) (бесплатно для Mac / Windows / Linux / Android).

### Шаг 2. Создайте колоду и импортируйте файл
1. Откройте Anki и нажмите кнопку **«Создать колоду» (Create Deck)** внизу окна. Назовите её, например: `Коран :: Частые слова`.
2. Выберите в меню **Файл -> Импорт** (или нажмите `Cmd+I` / `Ctrl+I`).
3. Выберите файл `quran_frequent_words.tsv` из этой папки.
4. В окне импорта проверьте соответствие полей:
   * **Тип карточки:** Базовый (или «Простой»)
   * **Колода:** `Коран :: Частые слова`
   * **Поле 1:** Лицевая сторона (Арабское слово `Arabic`)
   * **Поле 2:** Оборотная сторона (Перевод `Translation`)
   * **Теги (Tags):** Поле категории `Category` (позволит фильтровать слова по темам: глаголы, частицы, фразы).
5. Нажмите **«Импортировать»**.

---

## 💻 Вариант 2: Запуск тренажера в терминале

Если хотите потренироваться прямо сейчас без установки Anki:

```bash
python3 trainer.py
```

* Выберите категорию (например, только глаголы или только частые фразы).
* Тренажер будет показывать арабское слово с огласовками и транскрипцией.
* Нажмите `Enter`, чтобы увидеть перевод и пример использования, затем отметьте свой ответ.
