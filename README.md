## 🎯 В чём идея проекта?

1. **Лингвистический закон Парето:** Всего **~500 базовых корней** составляют более **80% всего объема текста Священного Корана**. В приложении собраны **130 главных корней и формул**, позволяющие понимать смысл аятов в намазе уже с первых недель.
2. **Классический метод «Тикрар» (تكرار):** Заучивание построено на проверенной веками методике многократных повторений и постепенного скрытия текста для эффективной самопроверки памяти.

## ✨ Ключевые возможности

### 1. 🕌 Поаятный Хифз 30-го Джуза (Джуз 'Амма)
* **Все 37 сур (от «Ан-Наба» до «Ан-Нас») — 564 аята** с переводом смыслов Эльмира Кулиева.
* **Фокус на одном аяте (Sequential Hifz):** Устраняет рассеивание внимания, переключение между аятами осуществляется кнопками или плавными жестами **свайпа влево/вправо**.
* **Интеллектуальная маскировка слов (Mask Mode 👁️):**
  * `Все слова` — полный текст со всеми огласовками (ташкилем).
  * `Каждое 2-е слово` — слова скрываются под маской `···`. Тапните по скрытому слову, чтобы мгновенно проверить себя!
  * `Первые буквы` — остаются только первые 2 буквы каждого слова как деликатный ориентир.
  * `Шторка` — полный скрытый режим для чтения строго по памяти.
* **Интерактивный счётчик повторений:**
  * Удобный тап-счётчик с анимацией и выбором цели (**3x, 5x, 7x, 10x повторений**).
  * Тактильный виброотклик (`haptic feedback`) на смартфонах при каждом тапе.
  * Кнопка фиксации статуса **«✓ Заучено»**.

---

### 2. 🗂️ Частотный словарь (130 карточек с двусторонней озвучкой)
Разбит на 4 фундаментальные коранические группы:
* 🎙️ **Фразы (25):** Главные формулы Корана (*«Фа-би-аййи а́ля́’и Раббикума́ туказзиба́н»*, *«Инна-Ллаха ʻаля кулли шей'ин кадир»*, *«Ас-самавати ва-ль-ард»*, *«Аль-хамду ли-Ллях»*...).
* 🔗 **Частицы / союзы / предлоги (40):** `مِنْ`, `فِي`, `مَا`, `لَا`, `إِنَّ`, `أَنَّ`, `عَلَىٰ`, `إِلَىٰ`, `الَّذِي`...
* ⚡ **Глаголы (30):** `قَالَ`, `كَانَ`, `آمَنَ`, `عَلِمَ`, `جَعَلَ`, `جَاءَ`, `عَمِلَ`, `خَلَقَ`...
* 🏷️ **Существительные (35):** `اللَّه`, `رَبّ`, `نَاس`, `إِنسَان`, `أَرْض`, `سَمَاء`, `يَوْم`, `كِتَاب`, `قَلْب`...

> 🎧 **Умный звук (Dual-Side Voice):**  
> На лицевой стороне звучит **только слово**, а при перевороте карточки чтец автоматически читает **целиком кораническую фразу-пример**.

---

### 3. 🎙️ Звук шейха Мишари Рашида аль-Афаси
* Студийное оригинальное звучание.
* Все 25 фраз нарезаны с микросекундной точностью строго по границам слов (без обрезки вакфов и без постороннего контекста).
* Регулировка темпа чтения в шапке приложения: **`0.75x`**, **`0.85x`**, **`1.0x`**, **`1.25x`**.
* Режим непрерывного зацикливания (**🔁 Повтор**).

---

### 4. 📊 Локальная база данных (IndexedDB + Статистика)
* Прогресс сохраняется в локальной базе данных браузера (`IndexedDB` + синхронное зеркало `localStorage`).
* **100% приватность:** Без регистрации, без отправки личных данных на сервер, без рекламы.
* Выдвижная шторка статистики: наглядные прогресс-бары заучивания Джуза и Словаря, учет выполненных тапов и выученных аятов.

---

### 5. 📱 Установка на телефон (PWA)
Приложение работает как нативное мобильное приложение:
* **На iPhone (iOS):** Откройте сайт в Safari ➔ нажмите кнопку **«Поделиться»** ➔ **«На экран "Домой"»**.
* **На Android:** Откройте сайт в Chrome ➔ нажмите меню (три точки) ➔ **«Установить приложение»**.
* **100% Оффлайн:** Благодаря Service Worker приложение и все тексты открываются даже в самолёте без подключения к интернету.

## 📁 Структура проекта

```text
words/
├── index.html                 # Главное веб-приложение (PWA)
├── manifest.json              # Манифест PWA (иконка, цвета, полноэкранный режим)
├── sw.js                      # Service Worker (Network-First для HTML, кэширование и оффлайн)
├── test_everything.py         # Автоматизированный тестовый набор (звук, аяты, DOM, словарь)
├── juz30_data.json            # Полная база 30-го Джуза (37 сур, 564 аята, перевод Кулиева)
├── words_data.json            # База 130 частых слов и выражений с метаданными
├── quran_frequent_words.tsv   # Структурированная таблица частотного словаря
├── slice_phrases_and_words.py # Скрипт точной нарезки аудио и загрузки слов
├── fetch_juz30.py             # Скрипт синхронизации 30-го Джуза с переводом
├── download_mishary.py        # Скрипт загрузки сур и аятов шейха Мишари
└── audio/                     # Локальная база студийных аудиофайлов MP3 и M4A
```
