## ✨ Ключевые возможности

### 1. 🕌 Заучивание 30-го Джуза (Хифз в стиле приложения Qaree)
* **Весь 30-й Джуз (Джуз 'Амма) целиком:** Все 37 сур (от суры 78 «Ан-Наба» до 114 «Ан-Нас») — **564 аята**.
* **Режим «Один аят за раз» (Sequential Hifz):** Концентрация на одном аяте без визуального шума. Удобная навигация кнопками или **свайпами влево/вправо**.
* **Прогрессивное скрытие слов (Word Masking 👁️):**
  * `Все слова` — полный усманический текст со всеми огласовками (ташкилем).
  * `Каждое 2-е слово` — половина слов скрыта под черточками `···`. *При тапе на скрытое слово оно открывается индивидуально для проверки памяти!*
  * `Первые буквы` — остаются только первые 2 буквы каждого слова как ненавязчивая подсказка.
  * `Шторка` — аят полностью скрыт для воспроизведения наизусть.
* **Большой счётчик повторений (Tap-to-Repeat / تكرار):**
  * Удобная кнопка тапания повторов для закрепления в памяти.
  * Быстрый выбор цели: **3x, 5x, 7x, 10x повторений**.
  * Тактильный виброотклик (`haptic feedback`) на смартфонах при каждом тапе.
* **Чтение шейха Мишари Рашида аль-Афаси:**
  * Студийная озвучка каждого отдельного аята.
  * Кнопка **🔁 Повтор** для бесконечного зацикливания аята на слух.

---

### 2. 🗂️ Частотный словарь Корана (SRS Карточки)
Лингвистический факт: **всего ~500 базовых слов покрывают более 80% всего текста Корана.**  
В приложении собраны **125 ключевых слов и устойчивых выражений**, разбитых на 4 понятные категории:
* **Фразы (20)** — устойчивые коранические формулы (*«Инна-Ллаха ʻаля кулли шей'ин кадир»*, *«Аль-хамду ли-Ллях»*, *«Аят аль-Курси»*, *«Хасбуна-Ллаху ва ниʻма-ль-Вакиль»* и др.).
* **Частицы / союзы / предлоги (40)** (`مِنْ`, `فِي`, `مَا`, `لَا`, `إِنَّ`, `أَنَّ`, `عَلَىٰ`, `إِلَىٰ`, `الَّذِي`, `هَٰذَا`, `هُوَ`...).
* **Глаголы (30)** (`قَالَ`, `كَانَ`, `آمَنَ`, `عَلِمَ`, `جَعَلَ`, `جَاءَ`, `عَمِلَ`, `خَلَقَ`...).
* **Существительные (35)** (`اللَّه`, `رَبّ`, `نَاس` [люди], `إِنسَان` [человек], `أَرْض`, `سَمَاء`, `يَوْم`, `كِتَاب`, `قَلْب`, `شَرّ`, `خَيْر`...).
* **Точное студийное аудио шейха Мишари:** На карточках фраз чтец произносит **СТРОГО ТОЛЬКО САМУ ФРАЗУ** (без лишнего контекста аята), а на словах — строго изолированное выверенное слово.

---

### 3. ⚡ Регулировка скорости чтения (0.75x – 1.25x)
В верхнем правом углу доступен переключатель скорости:
* **`0.75x`** — замедленно (для детального разбора махраджей и огласовок).
* **`0.85x`** — комфортный умеренный темп.
* **`1.0x`** — стандартный темп шейха Мишари.
* **`1.25x`** — быстрый темп для беглой проверки памяти.

---

### 4. 📱 Установка на телефон как родное приложение (PWA)
Приложение разработано по стандартам **Mobile-First & Apple Design**:
* Поддерживает вырез экрана (iPhone Dynamic Island / Notch) и системные жесты.
* **Как установить на iPhone:** В Safari нажмите кнопку **«Поделиться»** ➔ **«На экран "Домой"»**.
* **Как установить на Android:** В Chrome нажмите меню (три точки) ➔ **«Установить приложение»**.
* **Оффлайн-режим:** Благодаря Service Worker приложение и все тексты доступны даже в самолёте без интернета.

## 📁 Структура проекта

```text
words/
├── index.html                 # Главное веб-приложение (PWA)
├── manifest.json              # Манифест PWA (иконка, цвета, полноэкранный режим)
├── sw.js                      # Service Worker для кэширования и работы оффлайн
├── juz30_data.json            # Полная база 30-го Джуза (37 сур, 564 аята, перевод Кулиева)
├── words_data.json            # База 125 частых слов и выражений с метаданными
├── quran_frequent_words.tsv   # Структурированная таблица частотного словаря
├── trainer.py                 # Консольный тренажер на Python для терминала
├── slice_phrases_and_words.py # Скрипт точной нарезки аудио и загрузки слов
├── fetch_juz30.py             # Скрипт синхронизации 30-го Джуза с переводом
├── download_mishary.py        # Скрипт загрузки сур и аятов шейха Мишари
└── audio/                     # Локальная аудиобаза MP3 и M4A файлов
```
